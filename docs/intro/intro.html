一句话介绍

她不是摆设，是 dsh 的“工作状态指示灯”。

dsh 在干活，她就在你桌面上跟着忙：
收到任务会兴奋、跑命令会戴眼镜、要你批准会冒汗、干完会比耶。

收到任务→ 兴奋
跑命令→ 戴眼镜
要你批准→ 冒汗
干完→ 比耶

A方法 A最省事

把仓库链接 https://github.com/Dylan3589277/dsh-whale-pet 发给你的 dsh，说一句「帮我装这个」。

🧑‍💻
https://github.com/Dylan3589277/dsh-whale-pet

B方法 B一行命令

打开 PowerShell，粘贴回车：

PowerShell
irm https://raw.githubusercontent.com/Dylan3589277/dsh-whale-pet/main/install.ps1 | iex
♡想要可爱人设可选

让 dsh 用桌宠的语气说话，装的时候多加一句：

PowerShell
$env:DSH_PET_PERSONA='1'; irm https://raw.githubusercontent.com/Dylan3589277/dsh-whale-pet/main/install.ps1 | iex

PowerShell
